# KISSAN SATHI — Start Here

## Windows
1. Extract the ZIP into a new folder.
2. Open `kissan-sathi-phase1`.
3. Double-click `RESET-AND-RUN.bat`.
4. Wait a few seconds for the Server and Frontend windows.
5. Open **http://localhost:5173**.
6. Keep both command windows open while using the app.

If `localhost` says refused, look at the **Frontend** command window. If it shows an error, send that screenshot.
